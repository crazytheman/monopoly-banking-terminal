# Banking Terminal

A phone web app that replaces the card-reader unit of **Monopoly Ultimate Banking (B6677, Ukrainian edition "Банк без меж")**.
It reads the printed bar codes on the real Bank, Title Deed and Event cards with the phone camera and runs the banking rules:
balances, buying, rent levels, colour-set bonuses, auctions, Location, Jail, Event cards, debt and bankruptcy.

Open the page on a phone (it must be served over HTTPS for camera access), tap the reader, and hold a card's white bar-code strip inside the box.
